# Постовик

Блог на Next.js. Можно создать запись, открыть её, изменить и удалить. Список и открытый пост обновляются в других вкладках того же сервера без перезагрузки страницы.

Записи лежат в памяти процесса Node.js и пропадают после перезапуска сервера.

## Стек

- Next.js 16 (App Router), React 19, TypeScript.
- Стили — CSS Modules.
- Хранилище — `Map` в `globalThis` текущего процесса Node.js.
- Поток обновлений — `GET /api/posts/stream`.

Страницы и API, которые читают или меняют записи, работают в runtime `nodejs`. Несколько процессов или реплик не видят записи друг друга.

## Требования

- Node.js 20.9+.
- npm.

## Локальный запуск

В каталоге проекта:

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).
